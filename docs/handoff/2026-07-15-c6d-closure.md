## 4. Downstream Compatibility

- **Consumers unchanged**: No changes to event payload shapes, emission paths, or output formats.
- **Timestamp contract preserved**: Valid `ts` values (positive number, zero) emit normally. Invalid values silently dropped — previous behavior was to emit them, which could cause downstream consumer NaN/Infinity errors.
- **Config contract**: Previously no structural validation existed — invalid config would fail at arbitrary later access points with confusing errors. Now fails immediately with actionable messages.
- **Rollup/pipeline consumers**: Not affected.
